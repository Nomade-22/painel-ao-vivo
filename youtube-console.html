Visualizador para OBS

Esta página é independente do visualizador de MP4. Use o endereço abaixo como uma nova fonte Navegador no OBS.

Prévia

1. No OBS, clique em Fontes → + → Navegador.
2. Cole a URL copiada. Configure a largura/altura (ex.: 1080 × 1920 para LIVE vertical).
3. Ative Controlar áudio via OBS, quando disponível, e confira o Mixer de Áudio.
4. Se o navegador bloquear o som automático, use a opção Interagir do OBS para iniciar o player.

O player oficial do YouTube permanece visível. Alguns vídeos impedem incorporação ou autoplay. Para transmitir em LIVE, você precisa ter os direitos do conteúdo.
